# Release notes — 0.3.1 preview

This preview contains the local-first VS Code dashboard, project creation starters, optional monochrome theme and a separate optional Developer Pack. The setup ZIP installs prebuilt VSIX files and does not require Node.js for the user.

This is an early release. GitHub account integration requires sign-in and grants a write-capable scope; it is used for reading repositories. Local backup exports do not include project references or project folder contents. The Developer Pack can install several third-party extensions and its fresh Marketplace dependency flow depends on the main extension being published. Check the repository's release assets and checksums after publication.
