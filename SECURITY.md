# Security

Do not publish tokens, passwords, personal notes, authentication logs or private project files in issues.

Download release files only from the project's official GitHub Releases page or its verified Marketplace listing. Check the published SHA-256 checksums. Third-party extensions in the optional pack have their own publishers and privacy policies.

## Reporting a vulnerability

Prefer GitHub's private **Report a vulnerability** form in the [Security tab](https://github.com/AdnanNaous/cs-work-hub-downloads/security/advisories/new) when it is enabled. If GitHub does not offer the form, do not post exploit details or sensitive files publicly. Ask the owner to enable private vulnerability reporting using a minimal issue without vulnerability details, then submit the private report.

Include the affected version/commit, impact, and minimal reproduction using synthetic data. Never include live credentials, private project files, personal notes or authentication logs. No response-time commitment is implied.
